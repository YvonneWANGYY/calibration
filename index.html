Evidence chain

One active-learning engine, three astrophysical calibration surfaces.

The project is framed as a transferable calibration workflow rather than a one-off optimizer for a single simulation.

Sedov--Taylor

Profile-error calibration for AMR controls

The Sedov branch calibrates refinement thresholds that affect physical shock profiles and simulation cost, showing how adaptive search can move beyond fixed manual sweeps.

Rotating Cylinder

Transfer to a second Enzo calibration target

The Rotating Cylinder branch reuses the learned-proposal interface on an angular-momentum conservation task and tests runtime-aware acquisition behavior.

local SAGE

Semi-analytic galaxy-formation calibration

The SAGE branch calibrates eight SAGE-paper scale parameters against a multi-family observational target using the same active-learning orchestration layer.

Autonomous loop

A recipe materializes the run, then the loop advances itself.

The reusable engine combines CRQSF proposal learning, acquisition, simulator execution, and bookkeeping into a closed-loop calibration run after the case-specific recipe is specified.

01Recipe

Target, bounds, wrapper, resources, and initial design.

02Preflight

Validate paths, resource shape, strategy, and output plan.

03CRQSF proposal

Fit a target-conditioned learned proposal from evaluated rows.

04Acquisition

Select the next parameter vector with ranking, MAP, or sampling.

05Simulation

Run the astrophysical model through the case wrapper.

06Update

Append metrics, manifests, and history for the next iteration.

SAGE automation highlight

SAGE recipe-driven launcher

The SAGE recipe-driven launcher packages the target JSON, initial LHS summary, parameter range, CRQSF root, acquisition strategy, output naming, and PBS resources into one checked recipe. It replaces the most fragile hard-coded launcher fields with a preflighted JSON-to-PBS path. 

python scripts/launch_sage_calibration.py --recipe recipes/sage8_ensemble_map_20iter.json
python scripts/launch_sage_calibration.py --recipe recipes/sage8_ensemble_map_20iter.json --write-pbs --force

Edit before running: update the target paths, output identity, strategy controls, and PBS resources such as walltime, ncpus, nodetype, host, and ngpus for your local cluster.

Autonomy boundary

What "fully autonomous" means here

Autonomous means the closed-loop run proceeds after the recipe is specified. It does not mean the system invents the science target, parameter domain, simulator wrapper, PBS resource policy, or initial design. Those are researcher-defined inputs. The contribution is that the subsequent adaptive exploration, proposal fitting, acquisition, simulator dispatch, and run bookkeeping are encapsulated and reproducible.
